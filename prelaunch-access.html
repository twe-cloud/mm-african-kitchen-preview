Recommended process

Order of operations

  1. Sign/notarize agreement. No POS/payment/API access before the business agreement is in place.
  2. Collect the 4 access bundles. Domain, mailbox, Square, Uber/POS.
  3. Redirect old website traffic. First customer-facing win.
  4. Turn on business email. Update the site once mailboxes are verified.
  5. Validate Square access. Start read-only, then controlled payment path.
  6. Validate Uber order access. If API access is blocked, use fallback kitchen-ticket bridge while partner access is pursued.
  7. Protect Grubhub/TouchBistro. Keep current Grubhub routing stable while adding Uber/Square around it.
  8. Prepare the new POS adapter. Once vendor is chosen, map menu IDs and run parallel reconciliation before cutover.
